# ru_lcw_retail

Проект предназначен для подготовки и сборки артефактов 1С: конфигураций,
расширений конфигурации и внешних обработок. Исходные выгрузки хранятся
локально и не добавляются в Git; в репозитории сохраняются инструкции и
сценарии сборки.

## Каталоги

- `conf` — исходная файловая выгрузка типовой конфигурации;
- `extensions` — исходные файловые выгрузки расширений;
- `external` — исходники и файлы внешних обработок;
- `.build` — сценарии сборки, локальная информационная база и журналы.

## Сценарии сборки

- `.build/build-cf.bat` — сборка `.cf` из XML-выгрузки в `conf`;
- `.build/build-cfe.bat` — сборка расширения из `extensions`;
- `.build/build-ep.bat` — сборка внешней обработки из XML-выгрузки в `external`.

Подробности о назначении локальных каталогов находятся в README внутри них.
