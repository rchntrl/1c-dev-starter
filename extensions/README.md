# Исходники расширений

В этом каталоге размещаются локальные файловые выгрузки расширений 1С.
Для сборки `build-cfe.bat` ожидает исходники выбранного расширения в каталоге
`<имя расширения>` (например, `extensions/GS`) и файл `Configuration.xml`
внутри него.

Каталог и его содержимое, кроме этого README, игнорируются Git. Исходную
выгрузку следует хранить и обновлять локально.
