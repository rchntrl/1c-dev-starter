# Исходники расширений

В этом каталоге размещаются локальные файловые выгрузки расширений 1С.
Для сборки сценарий `build-cfe.ps1` ожидает исходники выбранного расширения в каталоге
`<имя расширения>` (например, `extensions/GS`) и файл `Configuration.xml`
внутри него. Запустить сценарий можно из корня проекта, например:

```powershell
.\.build\build-cfe.ps1 GS [версия-платформы]
```

Каталог и его содержимое, кроме этого README, игнорируются Git. Дамп расширения
можно добавить только в отдельную ветку, созданную от `main`, и публиковать
аннотированным тегом. Не вливайте такую ветку в `main`; порядок работы описан в
[корневом README](../README.md#правила-git).
