# Исходники конфигурации

В этом каталоге размещается одна файловая выгрузка конфигурации 1С для
последующей сборки файла `.cf`. Выгрузка располагается прямо в `conf`:
корневой файл — `Configuration.xml`, а связанные каталоги находятся рядом.
Не создавайте для неё отдельную подпапку.

Содержимое каталога, кроме этого README, игнорируется Git. Чтобы добавить
выгрузку в `main`, удалите из `.gitignore` правило `conf/*`, затем добавьте
содержимое каталога в Git:

```powershell
git add conf/
```

## Сборка файла `.cf`

Из корня репозитория запустите один из сценариев:

```powershell
.\.build\build-cf.ps1 [имя-конфигурации] [версия-платформы]
.\.build\build-cf.bat [имя-конфигурации] [версия-платформы]
```

Например:

```powershell
.\.build\build-cf.ps1 1Cv8 8.3.24.1691
.\.build\build-cf.bat 1Cv8 8.3.24.1691
```

Сценарий загружает дамп из `conf` в локальную информационную базу `.build/ib`
и сохраняет файл `.cf` в корне репозитория. PowerShell-сценарий по умолчанию
использует имя и платформу из `.build/parameters.yml` (или `1Cv8` и
`8.3.24.1691`, если файл или значения не заданы); командный файл `.bat`
использует `1Cv8` и `8.3.24.1691`. Имя результата PowerShell-сценария включает
дату сборки, например `1Cv8_2026-10-13.cf`; `.bat` создаёт `1Cv8.cf`.
