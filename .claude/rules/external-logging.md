# Логирование в модуле объекта внешней обработки

Дополняет [bsl-code-style.md](bsl-code-style.md). Для модуля объекта внешней обработки эти правила важнее
общего правила «писать в журнал и/или пробрасывать» из раздела «Сообщения и ошибки».

## Где логировать

- Методы логирования (`ЗаписьЖурналаРегистрации`, обёртки над ним вроде `ЗанестиВЖурналСобытий`) вызываются
  **только в главной процедуре** — процедуре команды, которую вызывает `ВыполнитьКоманду`
  (например, `SEND_DOCUMENTS`).
- Вспомогательные методы, вызываемые из главной процедуры, сами ничего не логируют и не показывают
  сообщения пользователю.

## Вспомогательные методы

Если во вспомогательном методе может возникнуть исключение (HTTP-запрос, чтение/запись данных, разбор JSON
и т. п.), он оформляется так:

- это функция, которая возвращает `Булево`: `Истина` — успех, `Ложь` — ошибка;
- последний параметр — выходной `Сообщение` (строка с описанием ошибки);
- код, который может вызвать исключение, обрамлён в `Попытка ... Исключение ... КонецПопытки`;
  в `Исключение` заполняется `Сообщение` (`ПодробноеПредставлениеОшибки(ИнформацияОбОшибке())`,
  при необходимости с контекстом: адрес, идентификатор) и возвращается `Ложь`;
- ошибки, обнаруженные без исключения (например, код ответа HTTP не 200), тоже возвращаются как `Ложь`
  с заполненным `Сообщение`;
- исключения из метода наружу не выпускаются; результат работы возвращается через другие выходные параметры.

```bsl
Функция ОтправитьДокумент(Подключение, ДанныеЗапроса, ДанныеОтвета, Сообщение)

	Попытка
		HTTPОтвет = ВыполнитьЗапрос(Подключение, ДанныеЗапроса);
		Если HTTPОтвет.КодСостояния <> 200 Тогда
			Сообщение = СтрШаблон("StatusCode %1 %2", HTTPОтвет.КодСостояния, HTTPОтвет.ПолучитьТелоКакСтроку());
			Возврат Ложь;
		КонецЕсли;
		ДанныеОтвета = JsonВОбъект(HTTPОтвет.ПолучитьТелоКакСтроку(), , Неопределено);
	Исключение
		Сообщение = Подключение.URI + Символы.ПС + ПодробноеПредставлениеОшибки(ИнформацияОбОшибке());
		Возврат Ложь;
	КонецПопытки;

	Возврат Истина;

КонецФункции
```

## Обработка результата в главной процедуре

Главная процедура проверяет результат каждого такого вызова. Если функция вернула `Ложь`:

1. записать `Сообщение` в журнал регистрации с уровнем `Ошибка`;
2. если вызов в цикле по элементам — `Продолжить` к следующему элементу;
   вне цикла — `Возврат` (дальнейшая работа без результата бессмысленна).

## Остановка при ошибке

Флажок `ОстановитьПриОшибке` ставится только на форме, то есть при интерактивном запуске
(`ИнтерактивныйРежим = Истина`, его устанавливает форма). Обёртка логирования может вызвать исключение
по этому флажку, чтобы прервать отправку и показать ошибку пользователю, но только в интерактивном режиме.
В фоновом или регламентном задании исключение не вызывается никогда: ошибка записывается в журнал,
а цикл продолжается. Поэтому условие исключения всегда включает `ИнтерактивныйРежим`:

```bsl
Процедура ЗанестиВЖурналСобытий(Событие, Идентификатор, Успех, Комментарий)

	// ...
	ЗаписьЖурналаРегистрации(Событие, Уровень, МетаданныеДляЖурнала, Идентификатор, Комментарий);

	Если Не Успех И ИнтерактивныйРежим И ОстановитьПриОшибке Тогда
		ВызватьИсключение Комментарий;
	КонецЕсли;

КонецПроцедуры
```

## Пример главной процедуры

```bsl
Процедура SEND_DOCUMENTS()

	ИмяСобытия = ПолучитьИмяСобытия("SEND_DOCUMENTS");

	Сообщение = "";
	Если Не ПолучитьДанныеДляОтправки(Результат, Сообщение) Тогда
		ЗанестиВЖурналСобытий(ИмяСобытия, Неопределено, Ложь, Сообщение);
		Возврат;
	КонецЕсли;

	Для Каждого Документ Из Результат Цикл

		Сообщение = "";
		Если Не ОтправитьДокумент(Подключение, Документ.ДанныеЗапроса, ДанныеОтвета, Сообщение) Тогда
			ЗанестиВЖурналСобытий(ИмяСобытия, Документ.Ссылка, Ложь, Сообщение);
			Продолжить;
		КонецЕсли;

		// обработка успешного результата

	КонецЦикла;

КонецПроцедуры
```
