# Именование во внешних обработках HTTP-обмена

Дополняет [bsl-code-style.md](bsl-code-style.md) для внешних обработок, которые публикуют HTTP-сервис
обмена или ходят в чужой по HTTP.

## Правило

- По умолчанию — как в [bsl-code-style.md](bsl-code-style.md): имена и ключевые слова по-русски
  (`Если ... Тогда`, не `If ... Then`; `Для Каждого ... Цикл`, не `For each ... Do`).
- По-английски — только обёртки, непосредственно работающие с HTTP/JSON:
  - процедуры и функции, реализующие метод HTTP-сервиса или вызываемые по имени метода обмена через
    диспетчеризацию по строке (`Выполнить(ИмяМетода + "(...)")`, команды в `ВыполнитьКоманду`) — имя
    обязано совпадать с именем метода на другой стороне обмена, например `PullVouchersChanges`,
    `PullEmployeesChanges`, `PULL_VOUCHERS_CHANGES`. Это не вопрос стиля: диспетчер вызывает процедуру
    по строке с именем метода, совпадение имён обязательно;
  - низкоуровневые HTTP/JSON-примитивы и их прямые помощники: `getJSONQuery`, `postJSONQuery`,
    `wrapfor`, `IsDataGotten`, `IsDataPosted` и аналогичные.
- Весь остальной код — сопоставление данных через СКД, работа с учётными данными, журналирование,
  визуализация, бизнес-логика — по-русски, включая управляющие конструкции. Не смешивать
  `Если/Тогда/Цикл/Попытка/Исключение` с `If/Then/For/Try/Except` внутри одного метода.

## Пример

```bsl
// Имя процедуры — английское: совпадает с именем метода обмена, вызывается по строке.
Процедура PullVouchersChanges(RequestData, ResponseData, StatusCode)

	// Тело — по-русски, даже в HTTP-обёртке.
	Если HTTPMethod = "GET" Тогда
		Результат = Новый ДеревоЗначений();
		// ...
	Иначе
		StatusCode = 404;
	КонецЕсли;

КонецПроцедуры
```
