# Привилегированный режим во внешних обработках

- Внешние обработки запускаются пользователями с полными правами, поэтому `УстановитьПривилегированныйРежим`
  в них не используется: не добавлять его в новый код и убирать из существующего.
- `УстановитьПривилегированныйРежим(Истина)` действует только на код текущего модуля: на методы,
  вызываемые из другого модуля (например, `ОбщегоНазначения.ПрочитатьДанныеИзБезопасногоХранилища`),
  он не распространяется. Поэтому обрамление такого вызова привилегированным режимом ничего не даёт.
- Если обработке понадобится работать с неполными правами, нужные методы других модулей придётся
  продублировать в модуле обработки и уже вокруг их кода устанавливать привилегированный режим.
