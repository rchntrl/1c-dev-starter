# Платформа 1С

- Все операции с 1С (сборка, загрузка, проверки, запуск) выполняются на версии платформы из
  `.build/parameters.yml` (ключ `platform`). Учётные данные базы — там же (`username`, `password`).
- `.build/build-cfe.ps1` читает версию сам. Скриптам навыков (`db-cfe-admin`, `db-load-xml`, `db-run` и др.)
  передавай её явно: `-V8Path "C:\Program Files (x86)\1cv8\<platform>\bin\1cv8.exe"`. Без `-V8Path` они
  выбирают самую новую установленную платформу, а она может не совпадать с нужной.
