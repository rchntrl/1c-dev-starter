# Версия и описание внешней обработки

При каждом повышении версии внешней обработки или отчёта (`ПараметрыРегистрации.Версия`
в `СведенияОВнешнейОбработке`) обновляй `ПараметрыРегистрации.Информация`. Этот текст показывается
в справочнике «Дополнительные отчёты и обработки».

- В начале — краткое описание: что делает обработка и что ей требуется (например, минимальная
  версия расширения). Обновляй его, если меняется назначение или требования.
- Затем — доработки трёх последних версий, по строке на версию, новая сверху:
  `Версия X.Y.Z: <что изменилось>`. Добавляя новую версию, удаляй строку четвёртой с конца.
- Текст — `НСтр` только с русским вариантом `ru = '...'`, английский не добавляй. Для этого текста
  правило о двух языках из [bsl-code-style.md](bsl-code-style.md) не действует.
- Реквизит `Информация` справочника `ДополнительныеОтчетыИОбработки` — Строка(1024): весь текст
  должен в неё укладываться.

```bsl
ПараметрыРегистрации.Версия = "1.4.1";
ПараметрыРегистрации.Информация = НСтр("ru = 'Обмен с маркетплейсом Kaspi.kz: ...
	|
	|Версия 1.4.1: ...
	|Версия 1.4.0: ...
	|Версия 1.3.0: ...'");
```
