# Сниппеты и тестовые сценарии

В этой директории хранятся небольшие автономные сценарии и тестовые данные
для отладки фрагментов кода проекта.

## Тесты восстановления кода маркировки

Файл `ВосстановлениеКодаМаркировки.bsl` содержит функцию
`ВосстановитьКодМаркировки`. Сценарий
`ТестВосстановленияКодаМаркировки.ps1` проверяет её на наборах проблемных
кодов маркировки.

Для запуска установите OneScript и убедитесь, что `oscript` доступен в `PATH`.
Из корневой директории проекта выполните в PowerShell:

```powershell
.\snippets\ТестВосстановленияКодаМаркировки.ps1
```

Если политика выполнения PowerShell блокирует локальные сценарии, запустите
его с разрешением только для текущего процесса:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\snippets\ТестВосстановленияКодаМаркировки.ps1
```
